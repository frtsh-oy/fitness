# Библиотека упражнений

Все упражнения приложения описаны в одной таблице Google Sheets: одна строка —
одно упражнение. Из неё берётся всё, что видно на карточке: название, техника,
видео, инвентарь, нагрузка по мышцам. Готовая тренировка
(`workouts/legs-mwf.js`) своих упражнений не хранит, а ссылается на строки
таблицы по ключу, поэтому поправленный в таблице текст попадает во все
тренировки сразу.

Что лежит в этой папке:

| файл | что это |
|---|---|
| `library.csv` | снимок таблицы как есть, в таком виде она была при последнем импорте. Нужен, чтобы в истории git было видно, что поменялось |
| `library.js` | то, что читает приложение. Строится импортом из `library.csv`, **руками не правится**: тест сравнит его с таблицей и поймает ручную правку |
| `index.js` | как приложение достаёт упражнение по ключу |

## Колонки таблицы

Первая строка таблицы — заголовки. Нужны все 36 колонок с этими названиями,
лишних и повторяющихся быть не должно; порядок колонок любой. Пустые строки в
конце таблицы импорт пропускает. Регистр и пробелы по краям в значениях со
списком вариантов не важны («Силовое» и « силовое » — одно и то же).

| колонка | что писать | правила |
|---|---|---|
| Ключ | устойчивый идентификатор, например `rdl` | строчная латиница, цифры и дефис, до 40 символов; уникален; **не меняется никогда** (см. ниже) |
| Название | как называется упражнение в приложении | не пусто |
| Тип | где стоит упражнение в тренировке | одно из: `разминка`, `разогрев`, `силовое`, `завершение` |
| Паттерн | какое это движение | одно из: `наклон от таза`, `присед`, `выпад`, `жим`, `тяга`, `кор`, `изолирующее`, `подвижность`, `растяжка`, `восстановление` |
| Мышцы (подпись) | короткая подпись для карточки: «Ягодицы и задняя поверхность бедра» | не пусто |
| Дозировка | «10–15 раз», «12–20 раз на сторону», «20–30 секунд» | не пусто |
| Техника | основной текст «Как выполнять» | не пусто |
| Уточнение | второй абзац под основным | можно оставить пустым |
| Видео | ссылка на ролик YouTube с меткой времени, например `https://www.youtube.com/watch?v=9aLdnLtIBhY&t=4s` | можно оставить пустым. Годятся ссылки `youtube.com/watch?v=…`, `youtu.be/…`, `youtube.com/shorts/…`, `youtube.com/embed/…`. Метка времени: `t=523`, `t=523s` или `t=8m43s`; нет метки — ролик с начала. Идентификатор и старт берутся из ссылки при импорте |
| Подпись видео | текст ссылки на ролик | можно оставить пустым — тогда подписью будет время начала, «8:43». Подпись без видео не принимается |
| Доп. видео | дополнительные ролики | можно оставить пустым. Каждый ролик с новой строки внутри ячейки (в Google Sheets: Cmd+Enter на Mac, Ctrl+Enter в Windows), в виде `подпись — ссылка с меткой времени`; между подписью и ссылкой длинное тире (—) с пробелами с обеих сторон, не дефис: импорт принимает только его |
| Прогрессия | как усложнять упражнение | можно оставить пустым |
| Инвентарь | что нужно для упражнения | `длинная резинка`, `мини-петля` или `без инвентаря`; если нужно несколько, через запятую |
| Одностороннее | выполняется на каждую сторону отдельно | `да` или `нет` |
| Сложность | уровень упражнения | **только у силовых**: `базовое`, `среднее` или `сложное`. У остальных пусто, иначе импорт откажет |
| Многосуставное | движется больше одного сустава | **только у силовых**: `да` или `нет`. У остальных пусто |
| двадцать колонок мышц | заголовок — название группы: Ягодичные, Средняя и малая ягодичные, Квадрицепсы, Задняя поверхность бедра, Приводящие, Икроножные, Прямая мышца живота, Косые мышцы живота, Разгибатели поясницы, Сгибатели бедра, Широчайшие, Верх спины, Трапеции, Грудные, Передняя дельта, Средняя дельта, Задняя дельта, Бицепс, Трицепс, Предплечья | пусто, `1` или `0,5` (`0.5` тоже принимается). `1` — группа работает как главная, `0,5` — помогает; пусто — не участвует. Хотя бы одна группа должна быть размечена; пустая разметка разрешена только паттерну `восстановление`, и то не у силового |

Нагрузка по мышцам лежит в отдельных колонках, а не в одной ячейке со списком:
так её видно и правится глазами, а при импорте она проверяется по заголовку.

Сложность, многосуставность и разметка мышц — инженерное суждение по описанию
упражнения, а не заключение специалиста по тренировкам. Их правильность
проверяет только человек: `docs/muscle-map.md` показывает их рядом с названиями
упражнений, в том числе раздел «Библиотека упражнений» со сложностью и
многосуставностью. Заметил неверное — правь в таблице и обнови библиотеку.

## Как обновить библиотеку

Поправь таблицу и выбери в её меню **Приложение → Выложить библиотеку**. Скрипт
отправит лист на проверку (импорт, сводка разметки, тесты) и через 2–3 минуты
покажет итог:

- «Выложено» — библиотека в приложении обновится ещё через 2–3 минуты. Если
  приложение было открыто, перезапусти его.
- «Изменений нет» — таблица совпадает с тем, что уже в приложении.
- «Не выложено» с ошибками по строкам — поправь названное в таблице и нажми
  снова. Что значат ошибки — ниже, «Если импорт отказал». Приложение при этом
  не меняется.
- «Не выложено» без строк, со ссылкой — сломалось не в таблице: передай ссылку
  тому, кто ведёт код.

Кнопка не удаляет упражнения: строка, пропавшая из таблицы, — отказ импорта (см.
ниже). Намеренное удаление делается руками, с флагом `--allow-removed`.

### Как поставить кнопку (один раз)

1. Токен GitHub, под аккаунтом владельца репозитория: github.com → Settings →
   Developer settings → Personal access tokens → Fine-grained tokens → Generate
   new token. Repository access: Only select repositories → `frtsh-oy/fitness`.
   Repository permissions: Contents — Read and write, Actions — Read-only.
   Срок — сколько разрешит GitHub. Скопируй токен.
2. В таблице: Расширения → Apps Script. Замени всё в файле `Code.gs` (или
   `Код.gs`) содержимым `tools/library-sync.gs` и сохрани.
3. Перезагрузи таблицу: появится меню «Приложение». Выбери «Доступ к GitHub…».
   Google один раз спросит разрешение для скрипта: это твой собственный скрипт,
   на предупреждении «Google не проверял это приложение» нажми «Дополнительные
   настройки» → «Перейти…» и разреши. Вставь токен.

Токен хранится в свойствах пользователя скрипта: другие редакторы таблицы его не
видят. Когда срок токена кончится, кнопка скажет «GitHub не принял токен» —
создай новый и вставь через тот же пункт меню. Поменялся `tools/library-sync.gs`
в репозитории — повтори шаг 2.

### Руками, без кнопки

Команды запускаются в терминале из папки проекта.

1. Поправь таблицу в Google Sheets.
2. Скачай лист файлом: Файл → Скачать → Формат CSV (.csv). Нужен путь к
   скачанному файлу.
3. Запусти импорт, подставив путь к скачанному файлу. Путь пиши в кавычках: в
   имени файла бывают пробелы.

       node tools/import-exercises.mjs "<путь к скачанному файлу>"

   Он перезапишет `library.csv` и `library.js`.

   Вместо файла можно дать ссылку на лист, опубликованный в вебе (Файл →
   Поделиться → Опубликовать в интернете, выбрать лист и формат CSV). Ссылку
   тоже пиши в кавычках: в ней есть знак `&`, и без кавычек терминал (zsh)
   откажется её разбирать:

       node tools/import-exercises.mjs "<ссылка на CSV>"

   Учти: публикация делает лист читаемым по этой ссылке для всех, у кого она
   есть. Таблицу сейчас публиковать не нужно; если опубликовал, остановить
   публикацию можно в том же окне.
4. Пересобери сводку разметки и просмотри, что в ней поменялось:

       node tools/muscle-report.js

   Сводка — `docs/muscle-map.md`, руками её не правят. Её пересобирают до
   тестов: тест сверяет сводку с генератором, и после любой правки разметки он
   краснеет, пока сводка не пересобрана.
5. Прогони тесты:

       npm test

## Если импорт отказал

Импорт принимает таблицу целиком или не принимает вовсе: если хоть одна строка
не проходит проверку, ни один файл не записывается, а в конце написано «Файлы не
записаны». Все найденные ошибки печатаются разом, каждая с номером строки (как в
Google Sheets: заголовки — строка 1) и названием колонки, например
`Строка 5, «Сложность»: …`. Поправь всё названное в таблице и запусти импорт
заново. Две ошибки останавливают разбор раньше остальных: нет колонки в
заголовке (строки без неё не прочитать) и незакрытая кавычка в ячейке (дальше
файл не разобрать).

Отдельный отказ — «ключ был в библиотеке и пропал из таблицы». Тренировки,
которые уже сохранены, ссылаются на упражнения по ключу, и удаление строки
сломало бы их, поэтому импорт такую таблицу не пропускает. Первым делом
проверь, не удалил ли ты строку случайно, и верни её. Если упражнение убрано
намеренно, запусти импорт с флагом `--allow-removed` и перечисли через запятую
именно те ключи, которые убираешь:

    node tools/import-exercises.mjs "<путь к файлу или ссылка>" --allow-removed=ключ1,ключ2

Флаг снимает отказ только для названных ключей; про остальные пропавшие импорт
по-прежнему откажет.

Если убранный ключ всё ещё используется готовой тренировкой (`workouts/*.js`),
то после импорта `item()` бросит ошибку «Нет упражнения … в библиотеке», а
`npm test` покраснеет. Поэтому сначала убери упражнение из тренировки, потом
запускай импорт с флагом.

## Ключ не меняется никогда

Ключ — это связь. По нему готовая тренировка находит упражнение, из него
строится идентификатор сегодняшней отметки «сделано», на него ссылаются
сохранённые тренировки. Если поменять ключ, отметки этого упражнения за сегодня
пропадут, а старые ссылки на него перестанут находить упражнение. Поэтому
название можно править сколько угодно, а ключ — нельзя. Если упражнение стало
другим по смыслу, заведи новую строку с новым ключом.

## Почему разметка такая

Здесь записаны решения по разметке мышц, которые не очевидны из таблицы. Они
стояли комментариями рядом с упражнениями в `workouts/legs-mwf.js`, пока
упражнения жили в нём. Теперь упражнения в таблице, а причины — тут, по ключу
упражнения.

- `chinese-squat` — икроножные вспомогательные: глубокий присед и подъём таза с
  выпрямлением ног держит голеностоп.
- `knee-raise` — икроножные вспомогательные: стойка на одной ноге, равновесие
  удерживает голеностоп.
- `glute-bridge` — икроножные вспомогательные: таз поднимается упором через
  стопы.
- `leg-press` — икроножные вспомогательные: резинка идёт поперёк середины стоп,
  и положение стопы приходится удерживать всё повторение.
- `breathing` — нагрузки нет вовсе, колонки мышц пусты: дыхание не тренирует
  ничего, и описание прямо говорит «без задержек и усилия». Прежние 0,5 на
  брюшную стенку были самым спорным местом разметки, вынесенным в
  `docs/muscle-map.md` на вычитку, — владелец программы подтвердил, что
  считать здесь нечего. Пустую разметку нагрузки схема разрешает только при
  паттерне `восстановление` (`NO_LOAD_PATTERN` в `workouts/schema.js`),
  поэтому он у этого упражнения и стоит: пустые колонки здесь — это
  утверждение «не тренирует ничего», а не забытая разметка.

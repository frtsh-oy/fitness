# «Что есть дома»: инвентарь человека в конструкторе

Дата: 2026-10-21. Дополняет спеку конструктора
`docs/superpowers/specs/2026-10-19-workout-builder-design.md` и отменяет в ней
не-цель «профиль инвентаря… решается заменой упражнения» — в части инвентаря.
Противопоказания («колено болит») по-прежнему не цель.

## Зачем

Владелец просит: «у кого-то может не быть гири, гантелей и т.д. или определённых
резинок». Библиотека начинает пополняться упражнениями не только с резинками
(соседние сессии разбирают ролики), и генератор не должен выдавать человеку
упражнение с гантелями, если гантелей у него нет. Заменять каждое такое
упражнение руками — ровно то, от чего конструктор должен избавлять.

## Что меняется

1. **Словарь инвентаря шире.** Было: длинная резинка, мини-петля, без
   инвентаря. Стало пять видов плюс «без инвентаря»:

   | id | подпись |
   |---|---|
   | `band_long` | длинная резинка |
   | `loop_short` | мини-петля |
   | `band_handles` | резинка с ручками |
   | `dumbbells` | гантели |
   | `kettlebell` | гиря |
   | `none` | без инвентаря |

   Словарь живёт в одном месте — модуль `gear.js` в корне (как `muscles.js`).
   Импорт таблицы, схема, строка «Нужно», шторка замены и экран берут его
   оттуда. Новый вид инвентаря — одна строка в `gear.js`.
   У упражнения инвентарь — список «нужно всё перечисленное» (как сейчас).
   «Без инвентаря» стоит только одно: «без инвентаря, гантели» — ошибка импорта.

2. **«Что есть дома».** Человек отмечает виды инвентаря, которые у него есть
   (переключатели, можно снять все). Упражнение подходит, если каждый его вид
   инвентаря отмечен или это «без инвентаря».
   - По умолчанию отмечены длинная резинка и мини-петля: приложение — про
     тренировки с резинками, и у тех, кто им уже пользуется, ничего не
     меняется.
   - Хранится только на устройстве (localStorage, ключ `gear-owned`, JSON-массив
     id). В CloudStorage не идёт: это настройка, а не данные, и синхронизацию
     можно добавить потом. Хранилище недоступно — выбор живёт до закрытия
     приложения, по умолчанию прежний.

3. **Где действует.**
   - Генератор: и подбор, и проверка «хватает ли упражнений уровню и зоне»
     идут по подходящим упражнениям. Переключатели стоят на экране генератора
     над уровнями; смена сразу пересчитывает, какие уровни и зоны доступны.
   - Ручная сборка: разминка, разогрев и завершение при старте берутся из
     подходящих; библиотека упражнений показывает только подходящие и рядом
     с фильтрами — те же переключатели.
   - Замена упражнения: кандидаты только из подходящих.
   - Сохранённые свои тренировки и готовая тренировка не фильтруются: человек их
     уже выбрал, а пропавшее молча упражнение — анти-цель конструктора.

4. **Отказ говорит правду.** Если уровню или зоне не хватает упражнений из-за
   инвентаря, а в библиотеке они есть с другим, текст называет это и говорит,
   с каким: «Для начального уровня с отмеченным инвентарём нет базовых
   упражнений на: бицепс. Есть с инвентарём: гантели.» Когда в библиотеке их нет
   вовсе — прежний текст «в библиотеке пока нет…». В библиотеке под фильтрами:
   «Найдено: 5 · ещё 3 с другим инвентарём». В шторке замены, когда подходящих
   нет, а с другим инвентарём есть: «Похожих упражнений с отмеченным инвентарём
   больше нет. Есть с инвентарём: гантели.»

5. **Карточка библиотеки называет инвентарь** — той же подписью, что в шторке
   замены.

6. **Отчёт о пробелах** (`tools/library-report.js`) печатает три профиля: весь
   инвентарь, только резинки (длинная и мини-петля), без инвентаря. По нему
   сессии наполнения видят, кому генератор пока откажет.

## Не цели

- синхронизация «Что есть дома» между устройствами;
- «или» в инвентаре упражнения («гантели или гиря»): это две строки таблицы;
- вес гантелей, жёсткость резинок;
- фильтр по инвентарю в готовой тренировке и в «Сегодня».

## Анти-цели

- упражнение исчезает из сохранённой тренировки из-за смены «Что есть дома»;
- генератор отказывает, а текст не говорит, что дело в инвентаре;
- «без инвентаря» нельзя отключить так, что не останется ничего: его и нет среди
  переключателей, оно доступно всегда.
